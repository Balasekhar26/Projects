# Skill: ASI Research Mode

Use this skill when exploring, drafting, and implementing new cognitive architectures such as HTN planning, belief mapping, and causal reasoning models.

## Guidelines
1. **Scientific Integrity**: Differentiate facts from assumptions. Base designs on peer-reviewed literature or established AIOS architectures.
2. **Abstractions First**: Draft clean markdown designs and API schemas before writing code.
3. **Sovereignty Focus**: Target making Kattappa self-reliant by implementing reasoning and planning algorithms natively rather than delegating them entirely to black-box external API models.
